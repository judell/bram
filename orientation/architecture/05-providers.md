# Providers: detail

Click-through detail for 05-providers.mmd. Facts are as of commit `e8a38ac0` (2026-11-02). The diagram is a data flow diagram. Its three processes are the Agent CLI, `bram-guard` and the Bram host; its three stores are the seeded conventions, the turn records and the state folder; its nine labeled arrows are the flows between them. The four providers, Claude, Codex, OpenCode and Antigravity, are drawn as one Agent CLI box, because to Bram they are one kind of thing: each loads the conventions, runs the guard, calls the lifecycle routes and records its turns. They differ only in the channel each flow uses, and the flow sections below list those channels per provider. The shared part is large: one PTY, one turn-state spine, one set of worklist handlers and one guard binary.

What every provider does, drawn once. Each loads the same conventions every session, each "through its own channel". [`src-tauri/src/guard.rs:48-93`](https://github.com/judell/bram/blob/e8a38ac08d3ac3a6323b712bb00ebf23aa4a0f05/src-tauri/src/guard.rs?plain=1#L48-L93) Each reaches the same worklist handlers: "Both transports dispatch through the same host-side handlers, so response kinds, consume-on-read, the inflight sentinel, and the auth checks are identical."
