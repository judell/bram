# A turn's lifecycle: detail

Click-through detail for 02-turn.mmd. Facts are as of commit `b2eb8e0b` (2026-10-31). Solid arrows are what code does on its own; the dashed arrow depends on the agent doing something Bram can't force. This is the path of one user turn. The Worklist gate (diagram 3) rides on top of it.

## Pane action

A gate button or the message box. Gate buttons run `submitAuthorizedWorklistTurn`: record the authorization first, and only if that succeeds send the turn text. [`app/__shell/helpers.js:729-749`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/helpers.js?plain=1#L729-L749) The message box and other controls call `toTurn` directly. The README describes the user side: tick items, click Start, Commit or Drop; with items selected a message "addresses that item". Otherwise "it's open-ended chat". [`README.md:76-76`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/README.md?plain=1#L76-L76) The buttons are described at [`README.md:52-62`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/README.md?plain=1#L52-L62).

## Draft files

Two kinds of files let the PTY carry only a short message. Feedback drafts: `queueFeedbackDraft` writes `resources/feedback-drafts/<feedbackId>.md`, because "long Iterate feedback can lose structure or get truncated" in a bracketed paste; the turn then carries "only a small feedbackRef". [`app/__shell/helpers.js:528-535`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/helpers.js?plain=1#L528-L535) Outbound envelopes: `frame_outbound_turn` writes `resources/outbound-turns/<id>.json` for substantial, image-bearing or multi-line sends and returns a compact frame; if the write fails "inline is always the safe fallback". [`src-tauri/src/lib.rs:44819-44830`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L44819-L44830) [`src-tauri/src/lib.rs:44821-44825`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L44821-L44825) [`src-tauri/src/lib.rs:22484-22494`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22484-L22494) Both directories are gitignored. ## Agent CLI

`claude`, `codex` or `opencode`. [`src-tauri/src/lib.rs:27334-27341`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L27334-L27341) Bram doesn't parse the CLI's answer into a reply; it watches signals around it (see the terminal output and JSONL turn-end scan arrows). Bram pins no expected model for each CLI. The versions it knows are those of the captured specimens: Claude Code 2.1.312, codex-cli 0.165.0, OpenCode 2.1.4 and a Cursor agent, all captured on 2026-10-28, each with a "Model and version" row saying where the version shows on screen. [`docs/agent-specimens/README.md:12-15`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/agent-specimens/README.md?plain=1#L12-L15) [`docs/agent-specimens/README.md:50-50`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/agent-specimens/README.md?plain=1#L50-L50)

## drain and bracketed paste

The drain holds `toShell` and `toTurn` while a blocking menu is displayed ("No operational timeout") and while a fresh agent CLI is still booting, because a paste into a bare shell "lands as literal text (and can execute)". [`src-tauri/src/lib.rs:21352-21363`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L21352-L21363) It also hands a send back to the message box when the foreground is a bare shell or a trust prompt is up. [`src-tauri/src/lib.rs:21377-21404`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L21377-L21404) Before the paste, the host prepends pending host notes, applies the envelope switch, strips control characters, and records the exact payload in an outbound-send ledger. [`src-tauri/src/lib.rs:22470-22498`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22470-L22498) The paste itself is `ESC Ctrl-U`, then `ESC[200~ text ESC[201~`, a 50 ms sleep, and a separate `\r`. [`src-tauri/src/lib.rs:22563-22563`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22563-L22563) [`src-tauri/src/lib.rs:22580-22582`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22580-L22582) [`src-tauri/src/lib.rs:22641-22646`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22641-L22646) The Enter is separate because a single burst once left the payload "rendered-but-unsubmitted in the composer for 61s". [`src-tauri/src/lib.rs:22574-22579`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L22574-L22579) On Windows the submit path differs.
