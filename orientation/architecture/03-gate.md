## Proposed item

The convention: "Default: every change request goes through `resources/worklist.json`." [`app/__shell/conventions.md:54-59`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L54-L59) A proposed item names files, with before/after prose in `resources/worklist-drafts/<id>.md`. [`app/__shell/conventions.md:101-108`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L101-L108) Writing it is "*asking*, not approval". [`app/__shell/conventions.md:263-268`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L263-L268)

The guard checks writes to `worklist.json`: inline `before`/`after` is denied with `worklist-inline-prose`, and a write whose `version` isn't the on-disk version plus one is denied with `stale-worklist-version`. [`src-tauri/src/guard_policy.rs:3885-3894`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/guard_policy.rs?plain=1#L3885-L3894) [`src-tauri/src/guard_policy.rs:3903-3933`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/guard_policy.rs?plain=1#L3903-L3933) Item order, ids and the draft layout are conventions, see [`app/__shell/conventions.md:206-222`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L206-L222).

## Authorization record

`resources/.worklist-authorization.json` holds `kind`, `ids`, recorded item bodies, `issuedAtMs`, `source`, `consumedAtMs`, `interruptedAtMs` and `commitToo`. It is "a **single slot**: a subsequent gate action replaces it." [`docs/authorization.md:129-136`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/authorization.md?plain=1#L129-L136) The TTL is `WORKLIST_AUTH_TTL_MS`, 30 minutes. [`src-tauri/src/lib.rs:153-153`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L153-L153) [`docs/authorization.md:162-166`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/authorization.md?plain=1#L162-L166) The writer is `write_worklist_authorization_record`. [`src-tauri/src/lib.rs:71098-71102`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L71098-L71102) The repo itself calls this record one of the "same-user writable artifacts, not cryptographically protected records." [`docs/authorization.md:254-258`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/authorization.md?plain=1#L254-L258) Both Start and Commit use kind `approved`; only apply-and-commit adds `commitToo`. [`docs/authorization.md:246-252`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/authorization.md?plain=1#L246-L252) A target design replaces this with per-(item, verb) grants; the doc says it is "**not shipped behavior**". ## Execution claim

`resources/.inflight-claim.json` is "execution state: the host writes it while a turn runs, retires it when the turn ends, and re-arms it next turn while an authorization is live." ## Agent edits

The convention allows edits only inside an authorized item, with stated opt-outs (an explicit `just do it` in the same turn, the `skip-worklist:` prefix, correcting code written in the current iteration, an uncommitted draft, issue-only forge work). [`app/__shell/conventions.md:60-94`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L60-L94) Unauthorized edits "land in someone else's commit". [`app/__shell/conventions.md:153-155`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L153-L155) Direct-edit grants are a separate sidecar with a one-hour lifetime. ## Applied item

A `status` of applied means changes are on disk and awaiting commit approval, and "a begun `proposed` item can be committable too". [`app/__shell/conventions.md:251-254`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L251-L254) The standard flow, in the conventions' words, is approved proposed, then advance to applied, then a separate commit approval, then prune. [`app/__shell/conventions.md:256-258`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L256-L258) `begunAtMs` is stamped by the host, never the agent. [`app/__shell/conventions.md:241-246`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L241-L246)

## Commit route

`handle_worklist_commit` is held under a lock for its whole body, so a re-POST "queues behind the in-flight commit". [`src-tauri/src/lib.rs:83205-83208`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L83205-L83208) Before it commits it rejects forge closing keywords, because the forge would auto-close the issue at push, "bypassing the close-on-commit dialog's explicit user consent". [`src-tauri/src/lib.rs:83225-83231`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L83225-L83231) It rejects session URLs. [`src-tauri/src/lib.rs:83241-83257`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L83241-L83257) In the Bram source repo it refuses unformatted Rust (`cargo fmt --check`, 409 `op=refuse-unformatted-rust`). [`src-tauri/src/lib.rs:83363-83376`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L83363-L83376) It refuses a commit that would split a jointly owned file (`op=refuse-joint-interval`). [`src-tauri/src/lib.rs:83497-83505`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L83497-L83505) The conventions add: "`worklist-commit` is single-shot per approval. On a timeout, never re-POST". [`app/__shell/conventions.md:402-404`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L402-L404)

## Git commit

Two paths. The ordinary one is conventional: path-scoped `git add -A -- <path>` then a path-scoped `git commit`, which runs normal commit hooks. [`docs/git-as-infrastructure.md:73-95`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/git-as-infrastructure.md?plain=1#L73-L95) When another begun item owns lines in the same file, `interval_stage_commit` builds the commit from interval patches in a temporary index, using `commit-tree` and `update-ref`. [`docs/git-as-infrastructure.md:181-231`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/git-as-infrastructure.md?plain=1#L181-L231) [`src-tauri/src/lib.rs:57991-57996`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L57991-L57996) [`src-tauri/src/lib.rs:58064-58064`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L58064-L58064) Because `commit-tree` runs no hooks, "it must enforce important repository gates before the plumbing commit". [`docs/git-as-infrastructure.md:93-95`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/git-as-infrastructure.md?plain=1#L93-L95) Pushing is separate: "Pushing is the user's". ## stages and commits

See Git commit. ## Drop

A Drop with feedback goes to the agent, which calls resolve then prune; a Drop without feedback completes in the host. [`app/__shell/conventions.md:305-305`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/app/__shell/conventions.md?plain=1#L305-L305) `handle_worklist_drop_direct` has the comment "Record the drop authorization (the pane click IS the authorization)". [`src-tauri/src/lib.rs:81482-81483`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/src-tauri/src/lib.rs?plain=1#L81482-L81483) The repo flags the exposure: the feedback-less route "creates its own grant without establishing that a pane click happened." [`docs/authorization.md:228-233`](https://github.com/judell/bram/blob/b2eb8e0b702970b3cfb160702268c51395cbe319/docs/authorization.md?plain=1#L228-L233) Drop "Removes the row, not the edits."
