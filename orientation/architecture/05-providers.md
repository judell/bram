# Providers: detail

Click-through detail for 05-providers.mmd. Facts are as of commit `b2eb8e0b` (2026-10-31). Solid arrows are what code does on its own; dashed arrows are instructions that depend on the model following them. The shared part is large: one PTY, one turn-state spine, one set of worklist handlers and one guard binary. The differences are mostly in how each provider is hooked in, how it reaches the host, and where it records turns.
